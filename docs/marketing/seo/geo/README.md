# Visibilité IA (GEO)

Le protocole d'un passage est décrit dans [`PROTOCOLE.md`](./PROTOCOLE.md). Les gabarits vides d'une
fiche de test et d'une grille de passage sont dans [`_modele/`](./_modele/) :

- [`_modele/test.md`](./_modele/test.md) — la fiche d'un test (un couple prompt × assistant).
- [`_modele/synthese-passage.md`](./_modele/synthese-passage.md) — la grille d'un passage.

## Liste de contrôle d'un passage terminé

- les vingt fiches de test sont présentes ;
- les six champs de chaque fiche sont remplis ;
- le niveau de preuve est posé sur chaque fiche ;
- aucune donnée personnelle ne figure dans une fiche ou dans la grille ;
- les preuves (sorties intégrales, captures) restent hors du dépôt public ;
- la grille est comparable au passage précédent (mêmes cinq prompts, mêmes quatre assistants).
